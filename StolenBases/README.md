# NPB2026 Stolen Bases

NPBのPlayByPlayで、
「盗塁成功」「盗塁失敗」「牽制アウト」
を抽出し、周辺情報（投手、捕手、打者など）を追加してまとめたもの。

付加する情報は JSON Patch (RFC 6902) を利用。手書き修正になるのでひな形を自動生成して編集する。

盗塁阻止率の計算に必要な「企図数」に数えるかどうかの扱いは難しい。たとえば以下は数えない。

- 投手からのけん制球により始まったプレーで、盗塁または盗塁失敗が記録されたとき
- 投球前に走者が飛び出すなどして、投手からの送球で始まったプレーで、盗塁または盗塁失敗が記録されたとき
- 本盗（数えたり、数えなかったりで基準がいまだによくわからない）

以下は数える。

- 捕手からのけん制球により始まったプレーで、盗塁または盗塁失敗が記録されたとき

## フォルダ構成等

- daily 一日単位のデータ
- patches 付加情報のパッチ
- verify 確認用
