# Players

- 12月からのデータをまとめる。
- 2025年12月2日に、保留者名簿が公示されて、名前ののらない選手は自由契約。
- 2025年公示の任意引退は11月までにすんでいるので対象外。
- 現役ドラフトがあって、FA移籍、ポスティングやトレードがある。
- 現役ドラフトの支配下公示は12月16日。
- ポスティング移籍した、村上、岡本、今井は１月以降に自由契約になったが、データは2025年に含まれる。
- 伏見らのトレードは11月、FAがらみのは、1/19 古市、1/30 田中
- 2/25 羽月が自由契約
